# Analises

Pasta de **documentos de análise e pesquisa** do site da Marpe (auditorias, planos de melhoria, pesquisas de canais).

## Convenção

- Um arquivo por análise, nomeado `ANALISE-<assunto>.md` (ex.: `ANALISE-MELHORIAS.md`).
- Incluir data da pesquisa/auditoria no corpo do documento.
- Quando a análise for implementada, adicionar uma linha de **STATUS** no topo apontando para o `CLAUDE.md` (que é a fonte da verdade sobre o estado atual do site).
- Análises antigas ficam aqui como **histórico** — não apagar sem necessidade.
